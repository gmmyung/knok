# knok-core

`knok-core` contains the shared graph IR, tensor type representation, parsing
helpers, type checking, and experimental static value-and-gradient graph
transforms used by the knok compiler and build-time tracing frontend.

Most users should depend on the top-level `knok` and `knok-build` crates rather
than using this crate directly.

Repository and user documentation:

https://github.com/gmmyung/knok
